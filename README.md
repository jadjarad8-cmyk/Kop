# 📊 Kop - أداة تحليل التداول الذكية

أداة تحليل تداول متقدمة وساحقة تدمج استراتيجيات متعددة وتعطيك إشارات دقيقة للدخول والخروج من الصفقات.

## ✨ المميزات

- 🎯 **استراتيجيات متعددة**: SMC, ICT, Order Flow, Moving Averages, RSI, MACD
- 📈 **تحليل فني متقدم**: تحديد نقاط الدخول والخروج تلقائياً
- 📱 **واجهة جوال متقدمة**: تعمل بكفاءة على الهاتف والديسكتوب
- 🔌 **اتصال مباشر بـ MT5**: سحب البيانات الحية
- 🚨 **تنبيهات فورية**: notifications وتنبيهات صوتية
- 💪 **محرك تحليل قوي**: معالجة آلاف البيانات بسرعة

## 🛠️ التكنولوجيا

- **Backend**: Python + FastAPI + WebSocket
- **Frontend**: Vue 3 + Tailwind CSS + PWA
- **Database**: PostgreSQL
- **MT5 Integration**: python-mt5
- **Real-time**: Socket.IO

## 📦 الهيكل

```
Kop/
├── backend/          # Python FastAPI
├── frontend/         # Vue 3 Web App
├── strategies/       # استراتيجيات التداول
├── mt5_connector/    # اتصال MT5
└── docs/             # التوثيق
```
